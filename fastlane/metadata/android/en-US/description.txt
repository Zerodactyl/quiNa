quiNa is a third-party Telegram client based on Nagram / NekoX with extra features and Material 3 Expressive polish.

Additional features over Nagram (quiNa exclusive):
- Restored official Telegram icons (Default, Vintage, Aqua, Premium, Turbo, Nox)
- Match message filters against link URLs
- Quick read reactions on long-click
- Bottom bar settings tab long-press shortcuts
- Strip tracking parameters from links
- Add comma after mention
- Full sensor round videos
- Material 3 Expressive wavy progress bars and dialog styling

Inherited from Nagram / NekoX:
- Most of Nekogram's features
- Unlimited login accounts
- Proxy: VMess, Shadowsocks, SSR, Trojan-GFW, public proxy relay, subscription support, Ipv6 MTProxy, SIP008/ssr/v2rayN/clash parsing, QR import, auto-switcher
- Stickers: custom emoji packs, add without pack, backup/restore/share
- Translation: OpenCC, InstantView, Google/Yandex, language-id
- Options: disable vibration, dialog sorting, skip 5-sec regret, no comment on forward, link preview toggle, ignore content restrictions, custom cache/server, block secret chats, disable trending
- Actions: delete all in group, unblock all, QR login, clear data, share as QR, combine message, editable text style, forced copy, invert reply, quick reply, undo/redo, chat preview, noise suppress
- UI: Telegram X style menus, Material themes, enhanced notifications, original file names, stats, etc.

Anti-Feature: Non-Free Network, since Telegram servers run proprietary software.
Reproducible builds: see metadata/dev.Zerodactyl.quiNa.yml and bin/fdroid/ scripts (universal APK for fdroid task, deterministic timestamp).
